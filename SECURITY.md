# Security

Shark Support runs inside Cura with the same rights as Cura. It does not use the network and only writes its own
preferences, its marker file and a self-check report in your temp folder. The installer writes only inside Cura's
data folders.

To report a security problem privately, use GitHub's **Security > Report a vulnerability** on this repository
(private vulnerability reporting). Please do not open a public issue for security problems.
